## Antes de enviar
1. **Download URL:** o SignPath exige uma página de download que **diga que o projeto usa a SignPath Foundation para assinar**. O README tem uma seção
   "Download" para isso. Crie também uma *Release* no GitHub com o instalador e a frase
   *"Free code signing provided by SignPath.io, certificate by SignPath Foundation"*.
2. **2FA:** o SignPath e o GitHub exigem verificação em dois passos para a equipe.
3. **Reputação:** a fundação avalia se o projeto é conhecido/usado. Um projeto novo e sem downloads **pode ser recusado**; nesse caso, volte a pedir
   depois de ter uso real (downloads, estrelas, relatos) ou use a Microsoft Store (ver `PROBLEMA-CERTIFICADO.md`).
